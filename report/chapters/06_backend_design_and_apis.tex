\section{Implémentation des Scènes d'Éclairage}

Chaque préréglage de scène définit des valeurs de luminosité par pièce, l'état des
fenêtres et l'état de la vanne gaz.

\begin{lstlisting}[style=codeblock,language=JavaScript,caption={Logique d'Activation de Sc\`{e}ne (backend/routes/floorplan.js)}]
const SCENES = {
  Morning:   { brightness: { 'Living Room':100,'Kitchen':100,'Bedroom':100,
                              'Bathroom':100,'Utility':100,'Garage':80 },
               windowsOpen: true,  valveOpen: true },
  Dinner:    { brightness: { 'Living Room':75,'Kitchen':75,'Bedroom':35,
                              'Bathroom':50,'Utility':30,'Garage':40 },
               windowsOpen: false, valveOpen: true },
  Cinematic: { brightness: { 'Living Room':8,'Kitchen':12,'Bedroom':10,
                              'Bathroom':15,'Utility':18,'Garage':20 },
               windowsOpen: false, valveOpen: false },
  Sleep:     { brightness: { 'Living Room':15,'Kitchen':10,'Bedroom':3,
                              'Bathroom':25,'Utility':10,'Garage':5 },
               windowsOpen: false, valveOpen: false }
};

router.post('/scene', protect, async (req, res) => {
  const { scene } = req.body;
  const config = SCENES[scene];
  if (!config) return res.status(400).json({ message: 'Scene inconnue' });

  const devices = await Device.find({ houseCode: req.user.houseCode });
  const updates = [];

  for (const device of devices) {
    if (['light','lamp','rgb-light'].includes(device.type)) {
      const bri = config.brightness[device.room] ?? 50;
      device.state = bri > 0;
      device.brightness = bri;
      updates.push(device.save());
      mqttClient.publish(`command/${device.mqttTopic}`,
        JSON.stringify({ state: bri > 0 ? 'ON':'OFF', brightness: bri }));
    }
    if (['window','blind'].includes(device.type)) {
      device.state = config.windowsOpen;
      updates.push(device.save());
      mqttClient.publish(`command/${device.mqttTopic}`,
        config.windowsOpen ? 'OPEN' : 'CLOSE');
    }
    if (device.type === 'valve') {
      device.state = config.valveOpen;
      updates.push(device.save());
      mqttClient.publish(`command/${device.mqttTopic}`,
        config.valveOpen ? 'OPEN' : 'CLOSE');
    }
  }

  await Promise.all(updates);
  await HouseState.findOneAndUpdate(
    { houseCode: req.user.houseCode },
    { lightingMode: scene },
    { upsert: true }
  );

  io.to(req.user.houseCode).emit('dashboard:state-updated', { scene });
  await logAudit(req.user, `Scene activee : ${scene}`, 'device', req.ip);
  res.json({ success: true, scene });
});
\end{lstlisting}

\section{Passerelle Socket.IO Temps Réel}

\subsection{Authentification et Adhésion aux Chambres}

\begin{lstlisting}[style=codeblock,language=JavaScript,caption={Authentification Socket.IO (backend/server.js)}]
io.use(async (socket, next) => {
  const token = socket.handshake.auth.token;
  if (!token) return next(new Error('Aucun token d\'authentification'));
  try {
    const decoded = jwt.verify(token, process.env.JWT_SECRET);
    socket.user = await User.findById(decoded.id).lean();
    next();
  } catch {
    next(new Error('Token invalide'));
  }
});

io.on('connection', (socket) => {
  const { houseCode, role, _id } = socket.user;
  if (houseCode) socket.join(houseCode);        // Chambre scopee a la maison
  socket.join(`role:${role}`);                  // Chambre de role
  socket.join(`user:${_id}`);                   // Chambre personnelle
  if (role === 'admin')  socket.join('house:admin');
  if (role === 'agency') socket.join('agency:global');
});
\end{lstlisting}

\section{Plan d'Étage 3D Isométrique}

Le plan d'étage est rendu comme une projection isométrique SVG avec des overlays interactifs.
Six pièces sont définies avec des coordonnées de mise en page fixes :

\begin{center}
\begin{tabular}{lcc}
\toprule
\textbf{Pièce} & \textbf{Position Grille} & \textbf{Appareils Hébergés} \\
\midrule
Salon     & (0,0) & Lumières, TV, AC, Caméra \\
Cuisine   & (1,0) & Lumières, Prises, Capteur Gaz, Vanne \\
Chambre   & (0,1) & Lumières, AC, Fenêtre \\
Salle de Bain & (1,1) & Lumières, Ventilateur \\
Utilitaire   & (2,0) & Lave-linge, Prises \\
Garage    & (2,1) & Porte, Caméra, Lumières \\
\bottomrule
\end{tabular}
\end{center}

\noindent Chaque tuile de pièce est un polygone parallélogramme rendu à un angle
isométrique. La couleur de la pièce passe dynamiquement du gris foncé (lumières éteintes)
au jaune chaud (lumières à pleine luminosité) en interpolant la couleur hexadécimale
selon la luminosité moyenne des lumières actives dans cette pièce.

\section{Revue et Rétrospective Sprint 3}

\begin{tcolorbox}[goalbox,title={Revue Sprint 3}]
\textbf{Complété :} 4 user stories sur 4 (37 PS). Plan d'étage interactif démontré. \\
\textbf{Points forts :} L'activation de la scène ``Cinéma'' a atténué toutes les lumières
à 8--18\% et le changement s'est reflété en temps réel dans un second onglet navigateur
en 150~ms. \\
\textbf{Rétrospective :}
\begin{itemize}[leftmargin=1cm,itemsep=2pt]
  \item \textbf{Ce qui a bien fonctionné :} Le scopage des chambres Socket.IO par code
        maison a élégamment géré l'isolation multi-locataire.
  \item \textbf{Défi :} La projection isométrique SVG a nécessité des calculs mathématiques
        importants pour les coordonnées de parallélogramme et le positionnement des overlays.
  \item \textbf{Amélioration :} Ajout de mises à jour UI optimistes pour éliminer la
        latence perçue sur les réseaux locaux lents.
\end{itemize}
\end{tcolorbox}
