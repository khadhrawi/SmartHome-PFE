\section{Variables d'Environnement Backend}

Créer \texttt{backend/.env} avec les variables suivantes :

\begin{lstlisting}[style=codeblock,language=,caption={backend/.env.example}]
# Serveur
PORT=5000
MQTT_PORT=1883
NODE_ENV=development

# Base de donnees
MONGODB_URI=mongodb://localhost:27017/smarthome

# Securite
JWT_SECRET=votre-secret-aleatoire-256-bits
BCRYPT_ROUNDS=10

# Google OAuth 2.0
GOOGLE_CLIENT_ID=votre-google-client-id
GOOGLE_CLIENT_SECRET=votre-google-client-secret

# IA Groq (optionnel, Melo desactive si absent)
GROQ_API_KEY=gsk_votre-cle-api-groq

# Email (Nodemailer - exemple Gmail)
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USER=votre-email@gmail.com
EMAIL_PASS=votre-mot-de-passe-application

# CORS
FRONTEND_URL=http://localhost:5173
BACKEND_URL=http://localhost:5000

# Codes d'acces
ADMIN_ACCESS_CODE=ADMIN2025
AGENCY_ACCESS_CODE=AGENCY2025
CONCIERGE_CODE=CONCIERGE2025

\section{Étapes d'Installation Complètes}

\begin{lstlisting}[style=codeblock,language=bash,caption={Commandes d'Installation}]
# 1. Cloner le depot
git clone https://github.com/username/SmartHome-PFE.git
cd SmartHome-PFE

# 2. Installer toutes les dependances Node.js
npm run install:all
# Equivalent a :
# npm install                          (racine)
# cd backend && npm install            (backend)
# cd ../frontend && npm install        (frontend)

# 3. Configurer l'environnement
cp backend/.env.example backend/.env
# Editer backend/.env avec vos valeurs

# 4. Demarrer les serveurs de developpement
npm run dev
# Utilise concurrently pour executer :
# - Backend  : cd backend && nodemon server.js (port 5000)
# - Frontend : cd frontend && vite (port 5173)
# - Courtier MQTT demarre automatiquement avec le backend sur le port 1883

# 5. Verifier les services
curl http://localhost:5000/api/auth/me       # Doit retourner 401 (pas 500)
# mqtt-explorer -> connecter sur localhost:1883
# Ouvrir http://localhost:5173            # Doit afficher la page d'accueil
\end{lstlisting}

\subsection{Étapes de Flashage}

\begin{enumerate}[leftmargin=1.5cm,itemsep=4pt]
  \item Connecter l'ESP32 à l'ordinateur via câble USB-C/micro-USB.
  \item Dans Arduino IDE : Outils $\to$ Carte $\to$ ESP32 Arduino $\to$ ESP32 Dev Module.
  \item Outils $\to$ Port $\to$ Sélectionner le port COM correct.
  \item Mettre à jour le SSID Wi-Fi, le mot de passe, l'IP MQTT et le code maison dans le croquis.
  \item Cliquer sur \textbf{Téléverser} (Ctrl+U). Attendre le message ``Téléversement terminé''.
  \item Ouvrir le Moniteur Série (115200 bauds) pour vérifier la connexion Wi-Fi et MQTT.
\end{enumerate}

\subsection{Résolution des Problèmes Courants}

\begin{description}[leftmargin=1.5cm,itemsep=8pt]
  \item[MQTT ne se connecte pas (ESP32) :]
    Vérifier que l'IP du courtier correspond à l'IP locale de la machine backend
    (\texttt{ipconfig} sous Windows). S'assurer que les deux appareils sont sur le même
    réseau Wi-Fi. Vérifier les règles de pare-feu pour le port TCP 1883.

  \item[Connexion MongoDB échouée :]
    Vérifier \texttt{MONGODB\_URI} dans \texttt{.env}. Si utilisation d'Atlas, ajouter
    votre IP à la liste blanche dans les paramètres d'accès réseau Atlas. Vérifier les
    identifiants.

  \item[Erreur de redirection Google OAuth :]
    S'assurer que \texttt{http://localhost:5000/api/oauth/google/callback} est ajouté
    aux URIs de redirection autorisés dans la console Google Cloud.

  \item[Urgence gaz ne se lève pas :]
    Vérifier que le compte admin est connecté (pas un compte résident). Seuls les
    utilisateurs avec le rôle \texttt{admin} peuvent appeler
    \api{POST /api/gas/clear-emergency}.

  \item[DHT11 retourne NaN :]
    Vérifier le câblage : broche DATA sur GPIO 23, VCC sur 3,3V, GND sur GND, résistance
    de tirage de 10~k$\Omega$ entre DATA et VCC. Essayer d'augmenter l'intervalle de lecture.
\end{description}
