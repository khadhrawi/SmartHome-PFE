\subsection{Algorithme de Génération du Code Maison}

Chaque admin se voit attribuer un code maison unique suivant le modèle
\texttt{[A-Z][0-9]\{4\}} (ex. : \texttt{I5402}). L'algorithme garantit l'unicité :

\begin{lstlisting}[style=codeblock,language=JavaScript,caption={G\'en\'eration du Code Maison}]
const generateHouseCode = async () => {
  let code, exists;
  do {
    const letter = String.fromCharCode(65 + Math.floor(Math.random() * 26));
    const digits = Math.floor(1000 + Math.random() * 9000);
    code = `${letter}${digits}`;
    exists = await User.findOne({ houseCode: code });
  } while (exists);
  return code;   // Unicite garantie en base de donnees
};
\end{lstlisting}

\subsection{Authentification à Deux Facteurs TOTP}

\begin{lstlisting}[style=codeblock,language=JavaScript,caption={Configuration et V\'erification 2FA (backend/routes/2fa.js)}]
// Etape 1 : Generer le secret TOTP et le QR code
router.post('/setup', protect, async (req, res) => {
  const secret = speakeasy.generateSecret({
    name: `SmartHome:${req.user.email}`
  });
  req.user.twoFATempSecret = secret.base32;
  await req.user.save();
  const qrCode = await QRCode.toDataURL(secret.otpauth_url);
  res.json({ qrCode, secret: secret.base32 });
});

// Etape 2 : Verifier le code TOTP et activer la 2FA
router.post('/verify', protect, async (req, res) => {
  const { token } = req.body;
  const verified = speakeasy.totp.verify({
    secret:   req.user.twoFATempSecret,
    encoding: 'base32',
    token,
    window:   1                       // tolerance +/-30 secondes
  });
  if (!verified)
    return res.status(400).json({ message: 'Code invalide' });

  req.user.twoFASecret  = req.user.twoFATempSecret;
  req.user.twoFAEnabled = true;
  await req.user.save();
  res.json({ message: '2FA activee avec succes' });
});
\end{lstlisting}

\section{Middleware JWT}

Toutes les routes protégées utilisent le middleware \texttt{protect} pour valider le token
JWT et attacher l'objet utilisateur à \texttt{req.user} :

\begin{lstlisting}[style=codeblock,language=JavaScript,caption={Middleware d'Authentification (backend/middlewares/authMiddleware.js)}]
const protect = async (req, res, next) => {
  const header = req.headers.authorization;
  if (!header?.startsWith('Bearer '))
    return res.status(401).json({ message: 'Aucun token fourni' });

  const token = header.split(' ')[1];
  try {
    const decoded = jwt.verify(token, process.env.JWT_SECRET);
    req.user = await User.findById(decoded.id).select('+twoFASecret');
    if (!req.user)
      return res.status(401).json({ message: 'Utilisateur introuvable' });
    next();
  } catch {
    res.status(401).json({ message: 'Token invalide ou expire' });
  }
};
\end{lstlisting}

\section{Publication MQTT des Commandes}

Les commandes sont publiées sur \mqtt{command/\{topicMQTT\}} avec un payload spécifiant
l'état cible. L'ESP32 s'abonne à \mqtt{command/\#} et analyse le suffixe du topic pour
identifier quel actionneur contrôler.

\begin{lstlisting}[style=codeblock,language=C++,caption={Callback MQTT ESP32 (SmartHome\_ESP32.ino)}]
void mqttCallback(char* topic, byte* payload, unsigned int length) {
  String topicStr(topic);
  String msg;
  for (unsigned int i = 0; i < length; i++) msg += (char)payload[i];
  msg.trim();
  msg.toUpperCase();

  // Normalisation des variantes de payload
  bool isOn  = (msg=="ON"||msg=="TRUE"||msg=="OPEN"||msg=="UNLOCK"||msg=="1");
  bool isOff = (msg=="OFF"||msg=="FALSE"||msg=="CLOSE"||msg=="LOCK"||msg=="0");

  // Routage par topic
  if (topicStr.endsWith("/alarm")) {
    if (isOn) tone(BUZZER_PIN, 1000);
    else      noTone(BUZZER_PIN);
    return;
  }
  // LEDs RGB
  for (int i = 0; i < NUM_LEDS; i++) {
    if (topicStr.endsWith(ledTopics[i])) {
      int bri = isOn ? 100 : 0;
      if (!isOn && !isOff) bri = msg.toInt();
      setRGBBrightness(i, bri);
      return;
    }
  }
  // Servo porte
  if (topicStr.endsWith("/door"))
    { doorServo.write(isOn ? 180 : 0); return; }
  // Servo fenetre
  if (topicStr.endsWith("/window"))
    { windowServo.write(isOn ? 180 : 0); return; }
}
\end{lstlisting}
