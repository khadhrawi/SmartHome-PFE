\chapter*{Acknowledgments}
This report documents the full design and implementation journey of the SmartHome IoT Platform. The work consolidates software engineering, IoT integration, real-time communications, cybersecurity, data engineering, and user experience. I would like to acknowledge the support of my supervisors, colleagues, and family.

\chapter*{Abstract}
This PFE presents a complete smart home management platform developed as a monorepo with a Node.js backend and a React frontend. The system integrates MQTT for device telemetry and command flows, Socket.IO for user-facing real-time notifications, and MongoDB for persistence. The platform supports multiple roles (agency, house owner/admin, and resident), includes safety-critical gas emergency handling with valve and alarm control, and provides access control through resident permission requests.

The project applies layered architecture, event-driven integration, and secure authentication (JWT + OAuth). It also introduces operational workflows such as owner account requests, unit onboarding, role-based dashboards, and house-level governance. This report includes requirement analysis, UML modeling, architecture diagrams, implementation details, testing strategy, deployment guidelines, security evaluation, risk analysis, and future improvements.

\chapter*{Resume}
The SmartHome platform centralizes smart device supervision, home safety workflows, and multi-unit management in one extensible software product. It demonstrates how modern web technologies and IoT protocols can be combined to create a scalable and maintainable system suitable for real-world residential operations.
